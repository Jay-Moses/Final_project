# 🧑‍🏫 Automated Attendance System Using Group Photo and Face Recognition

A Python-based desktop application that automates class attendance by recognizing student faces from a group photo. Built with Tkinter for the GUI, OpenCV for image processing, and a local MySQL database for data storage.

## 📌 Features

- 📷 Capture or upload a group photo via the Tkinter interface.
- 🧠 Detect and recognize multiple faces using `face_recognition`.
- 🗃️ Store and manage attendance records in a local MySQL database.
- 🧑‍🏫 Admin panel to register students and view attendance.
- 👨‍🎓 Students can check their attendance through the GUI.

## 🧰 Tech Stack

- **Language:** Python
- **GUI:** Tkinter
- **Face Recognition:** OpenCV, face_recognition
- **Database:** MySQL (Local)
- **Others:** Pillow, NumPy, mysql-connector-python
